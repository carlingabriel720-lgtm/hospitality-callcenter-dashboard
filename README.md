# Multi-Year Hospitality Operations & Demand Dashboard (2023–2026)

An advanced, interactive executive operations dashboard engineered for high-end hospitality venues and reservation centers. This tool transforms raw inbound call logs into actionable intelligence for staffing allocation, capacity planning, and macroeconomic seasonal budgeting.

Key Features
- **Shift Scheduling Heatmap:** Identifies peak saturation periods across days and hours to optimize team rostering and eliminate idle labor costs.
- **Macro Seasonality & Monthly Trends:** Year-over-year comparative analysis (2023–2026) supporting financial forecasting and strategic hiring.
- **Weekly Effort Distribution:** Visualizes cumulative operational load by day of the week to balance workforce fatigue and infrastructure support.
- **Hourly Demand Curve:** High-precision trajectory mapping with interactive time-range sliders to justify operational hours.

Tech Stack & Architecture
- **Language:** Python 3.x
- **Data Wrangling:** Pandas (Aggregations, chronological mapping, strict data sanitization pipelines).
- **Visualization & Interactivity:** Plotly Express (Custom color mapping, responsive HTML embedding).
- **Design & UI:** Custom CSS inspired by luxury hospitality standards (Cinzel & Montserrat typography, high-contrast palette).
